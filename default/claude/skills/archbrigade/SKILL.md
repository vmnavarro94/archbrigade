## Activation Contract

Use for ANY request involving:
- Files in `~/.config/hypr/`, `~/.config/waybar/`, `~/.config/walker/`, `~/.config/mako/`
- Terminal configs: alacritty, foot, kitty, ghostty
- Files in `~/.config/archbrigade/`
- Window rules, animations, opacity, blur, gaps, borders, layer rules, workspaces
- Themes, backgrounds, fonts, appearance
- `archbrigade-*` scripts
- Screenshots, night light, idle behavior, lock screen, reminders

**Do NOT use** for ArchBrigade source development (`~/.local/share/archbrigade/`, `archbrigade-dev-*` workflows).

## Hard Rules

1. **NEVER edit `~/.local/share/archbrigade/`** — git-managed, changes lost on update
2. Reading `~/.local/share/archbrigade/` is safe — do it freely to understand defaults
3. All edits go in `~/.config/`; custom themes in `~/.config/archbrigade/themes/<name>/`
4. Backup before ANY edit: `cp <file> <file>.bak.$(date +%s)`
5. After Hyprland changes: `hyprctl reload && hyprctl configerrors` — fix all errors before finishing
6. After Waybar changes: `archbrigade-restart-waybar` (does NOT auto-reload)
7. `archbrigade-refresh-*` resets config to defaults — **ALWAYS ask user confirmation first**
8. Before writing window rules: fetch current syntax from Hyprland wiki (format changes frequently)
9. Before re-binding a key: check `archbrigade-menu-keybindings --print`; add `unbind` if key is already used; tell user what was unbound
10. There is NO unified `archbrigade` CLI — use individual `archbrigade-*` scripts directly
11. `~/.config/hypr/monitors.conf` is auto-generated by nwg-displays — do NOT edit manually

## Decision Gates

| Request | Action |
|---------|--------|
| Script exists for the task | Use it directly (`archbrigade-<verb>-<noun>`) |
| Config edit | Edit `~/.config/`, never `~/.local/share/archbrigade/` |
| Theme customization | Create dir `~/.config/archbrigade/themes/<name>/` |
| Package install | `archbrigade-pkg-add <pkg>` (AUR: `archbrigade-pkg-aur-install`) |
| Unknown script | `ls ~/.local/share/archbrigade/bin/` |
| Monitor config | Use nwg-displays GUI — do NOT hand-edit monitors.conf |

## Execution Steps

1. Read current config
2. Backup: `cp <file> <file>.bak.$(date +%s)`
3. Apply change with Edit tool
4. Validate/restart per Hard Rules above

## Script Discovery

No unified CLI. List all available scripts:

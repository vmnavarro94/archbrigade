# ArchBrigade Config File Locations

## Hyprland

```
~/.config/hypr/
├── hyprland.conf      # Main config (sources archbrigade defaults + user overrides)
├── bindings.conf      # User keybindings (overrides)
├── monitors.conf      # ⚠ AUTO-GENERATED by nwg-displays — do NOT hand-edit
├── input.conf         # Keyboard/mouse settings
├── looknfeel.conf     # Appearance overrides (gaps, borders, animations)
├── envs.conf          # Environment variable overrides
├── autostart.conf     # Startup applications
├── hypridle.conf      # Idle behavior
├── hyprlock.conf      # Lock screen
├── hyprsunset.conf    # Night light
├── apps/              # Per-app window rules
├── bindings/          # Binding sub-files (media, tiling, utilities)
├── windows.conf       # Window rules
└── workspaces.conf    # Workspace config
```

Auto-reloads on save. Always validate: `hyprctl reload && hyprctl configerrors`

Load order in `hyprland.conf`: archbrigade defaults first → user overrides second.
User files override defaults via re-declaration.

## Waybar / Walker / Mako

| App | Location | Reload |
|-----|----------|--------|
| Waybar | `~/.config/waybar/config.jsonc`, `style.css` | `archbrigade-restart-waybar` |
| Walker | `~/.config/walker/config.toml` | `archbrigade-restart-walker` |
| Mako | `~/.config/mako/config` | — |

## Terminals

| Terminal | Location |
|----------|----------|
| Alacritty | `~/.config/alacritty/alacritty.toml` |
| Kitty | `~/.config/kitty/kitty.conf` |
| Ghostty | `~/.config/ghostty/config` |

## ArchBrigade-specific

```
~/.config/archbrigade/
├── themes/            # Custom + stock theme dirs
│   └── <name>/        # Each is a real directory
├── current/
│   ├── theme          # Symlink → active theme dir
│   └── background     # Current background path
└── branding/          # System identity files
```

## Archbrigade defaults (READ-ONLY — never edit)

```
~/.local/share/archbrigade/
├── bin/               # All archbrigade-* scripts (on PATH via envs.conf)
├── config/            # Default config templates
├── default/           # Hyprland defaults (sourced by hyprland.conf)
├── themes/            # Stock themes
└── migrations/        # Update migrations
```
